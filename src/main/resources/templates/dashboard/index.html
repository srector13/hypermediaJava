JDBC vs JPA, same UI

One controller and one set of templates. A query inspector shows the SQL each technique runs: one round-trip with COUNT(*) OVER() vs. page + count.

JdbcClient · JpaSpecificationExecutor

Inline edit & validation

Rows swap into editors and back. Bean Validation errors render beside the field (HTTP 422), and concurrent edits are caught with optimistic locking (HTTP 409).

hx-put · hx-include="closest tr" · @Version

Infinite scroll, keyset paging

The last row loads the next batch when it scrolls into view. Seek pagination keeps batch 500 as fast as batch 1.

hx-trigger="revealed" · Window<T>

Real-time, multi-user

Every tab holds one SSE connection. When a row changes, the server broadcasts employee-{id} and any tab showing that row re-fetches it. Start the simulator, then open a table page to watch rows update by themselves.
